To Run:
1. Install python and pygame (see How To Install Python.txt).
2. Run coffee.py (try with CLI if necessary).

Organization:
- Source files in this folder.
- Compiled python files required to run the program in __pycache__ folder
- Graphics/sounds/music in assets folder.
- Data in csv files, read on program startup.
